# 拾词（Shici）

一个面向个人自定义词库的移动端背单词网站，按艾宾浩斯复习节奏安排学习。

## 功能

- 导入 TXT / DOCX 词表
- 多词库管理与重复词合并
- OpenAI 兼容 API 生成例句、翻译和相近释义干扰项
- 四选一中文释义练习与认识 / 模糊 / 不认识自评
- 1、2、4、7、15、30 天复习间隔
- 浏览器语音合成，支持美式和英式英语
- 本地学习记录、备份恢复与 PWA 添加到主屏幕

## 词表格式

每行一个词条：

```text
abandon v. 放弃；遗弃
look after 照顾；照料
```

## 本地运行

这是一个无需构建工具的静态网站。用任意静态文件服务器打开 `index.html` 即可；在手机上部署到 HTTPS 地址后，可以通过 Safari 的“添加到主屏幕”安装为 PWA。

AI 例句生成需要在“设置与备份”中填写 OpenAI 兼容 API 地址、模型名称和 API 密钥。数据保存在当前浏览器本地。
